# CSES v0.5.0: communications audit, code-of-conduct comparison, Unity

## Communications audit

The scanner now builds an inventory of every way children can communicate (chat SDKs, message tables,
direct messages, voice and video, comments, live streaming) and of the safeguards around them: report,
block, moderation roles, automated filters, link and contact-detail filtering, rate limits, preset
messages, retention, teacher visibility. It appears in the report, the dashboard, PDF and Word.

Nine new rules, **CORE-CHT-01 to 09**, from EU KIDS Act Art. 12, 15(2) and Recital 36 and DSA Art. 16:
declared channels, report and block everywhere, moderation by people and tools, direct messages only with
approved contacts, no links or contact details, voice, video and live streaming off by default, protected
media, a safeguarding procedure, and message retention.

A safeguard "not found" in code may live in a chat provider's dashboard, so these findings are REVIEW
unless a risky default is explicit in code (for example `voiceChatEnabled: true`).

## Code-of-conduct comparison

`tooling/coc.py` compares any code of conduct (PDF, Word, HTML, Markdown or text) with:

- what the EU KIDS Act proposal expects of codes (Art. 17, Art. 23, Recital 39);
- every CSES rule in scope: covered, partial, missing, or possible conflict, with the clauses cited.

The tool reads English wording; confirm results by reading the clauses, or use the Claude skill, which
compares meaning in any language.
