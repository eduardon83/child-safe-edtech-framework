      How this page handles your files

      The CSEF tools are Python programs. This page runs them inside your browser with Pyodide, which the page downloads from the jsDelivr CDN the first time. Your files are read by the browser and never sent anywhere: there is no server behind this page, no account and no analytics. Close the tab and everything is gone; download the results you want to keep.

      Organisations that block CDNs can host Pyodide themselves and open this page with ?pyodide=https://their-host/pyodide/. Developers get the same results, and the code checks, with tooling/workbench.py and tooling/scan.py.
