# Waiver / decision record

Use when the team decides to accept a gap against a CSEF rule. Add the short form to `waivers:` in
csef.yaml so the scanner reports it as WAIVED instead of failing.

| Field | Value |
|---|---|
| Rule | e.g. C-ENG-02 |
| Scope (files or feature) | |
| Decision | Accept / accept with conditions |
| Reason | |
| Risk to children, after measures | |
| Compensating measures | |
| Approved by (name, role) | |
| Expires (date) | |
| Review owner | |

A waiver can only be approved by someone accountable for child safety or data protection (e.g. DPO,
product owner with delegated authority). Waivers of Level 1 MUST rules need legal advice on file.
