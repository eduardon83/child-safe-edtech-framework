# Garden of Numbers: design document (example)

## Goal
Pupils aged 6 to 9 understand and compare simple fractions.

## Learning in the game
Each garden plot is split into equal parts. To plant, the pupil chooses the fraction the task asks for.
Paths to new plots open only when a task is solved. Decorations appear between tasks, never during one.

## Team
Two game designers, two primary teachers and a maths education researcher worked together from the first
prototype. Pupils tested each version.
